# NEAR: регулярность потоков за 30/90 дней

Окно 2026-08-06 ≤ UTC date < 2026-11-04. См. [FINDINGS.md](FINDINGS.md).

Публичный BigQuery → локальный JSON → точные целочисленные/Decimal расчёты → контроль недельного пересечения и сопоставление выплат.

Офлайн повтор анализа: `python3 research/near-longitudinal/scripts/analyze.py`.

SQL сохранён для воспроизводимости; повторно выполнять его в облаке не требуется. Массовая остановленная RPC-сверка не возобновлялась.
