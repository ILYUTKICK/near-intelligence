# Долларовая оценка потока покупки NEAR

Окно: 06.08–03.11.2026 UTC. [Выводы и ограничения](FINDINGS.md).

- `data/`: публичные HTTP-ответы CoinGecko, DefiLlama, NEAR Revenue Dashboard и исходники адаптеров.
- `scripts/analyze.py`: офлайн-сопоставление с предыдущей BigQuery-выгрузкой, ежедневная оценка USD по двум ценовым привязкам, сравнение источников.
- `analysis/daily.json`, `summary.json`: точные расчёты и агрегаты.
- `scripts/plot.py`: график сравнения динамики; требует matplotlib.

Запуск из корня проекта: `python3 research/near-dollar/scripts/analyze.py`.

Дневная цена — приближение; результаты не являются точными ценами исполнения. Данные объёма/комиссий взяты у поставщиков, а не независимо реконструированы из всех обменов.
