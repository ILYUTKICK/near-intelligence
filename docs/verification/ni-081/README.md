# NI-081 — methodology reading experience

## Design brief

The public page should answer a reader's trust questions before exposing operator
instructions. Keep the established warm canvas, navy serif type, green accents
and quiet dividers. No new visual system, dependency or decorative motion.

The reading order is: source families → metric meanings → preparation and version
flow → inspect a chart → interpretation limits → reproduce the evidence. A
compact chapter index supports scanning; the article stays at a comfortable
reading width. Three source-family rows and a metric comparison replace repeated
technical panels. A numbered process and a concrete verification guide connect
the explanation to the product's actual chart controls.

Primary text keeps the meaningful caveats visible: historical coverage, shared
Dune lineage, cohort limits, fees versus revenue, purchases versus burns, bounds,
missing observations and association versus causation. Full provider access and
reuse details, readiness verdicts/policy and real commands remain in native
keyboard-accessible disclosures. Internal task IDs and unimplemented command
backlog leave the main reading path. Existing canonical anchors are preserved.

This is a local design iteration under the owner's Git publication hold. It does
not change source verification dates, execute collection, publish a model or
establish any new provider entitlement.
