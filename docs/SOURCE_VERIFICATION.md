## Findings from current official sources

- [NEAR RPC providers](https://docs.near.org/api/rpc/providers) and [block/chunk interface](https://docs.near.org/api/rpc/block-chunk) support source selection and block-hash pinning. Do not reuse historical generic “600 requests/minute” advice.
- [Intents documentation index](https://docs.near-intents.org/llms.txt) lists Explorer and OpenAPI; [fee configuration](https://docs.near-intents.org/integration/distribution-channels/1click-api/fee-config) defines appFees parameters. Neither alone verifies historical fee receipt or protocol entitlement. An initially guessed Explorer URL failed; use the published index rather than guessed paths.
- [DefiLlama adapter](https://github.com/DefiLlama/dimension-adapters/blob/master/fees/near-intents/index.ts) distinguishes gross fees and wallet-based revenue and excludes internal treasury hops. Treat its labels as provider methodology, not independent proof of all fee funding. [API access documentation](https://docs.llama.fi/pro-api) distinguishes open access and paid API tiers.
- [Dune authentication](https://docs.dune.com/api-reference/overview/authentication) and [rate limits](https://docs.dune.com/api-reference/overview/rate-limits) must be applied to the actual account and endpoint. Reading docs does not authorize billed query execution.
- [CoinGecko historical range](https://docs.coingecko.com/reference/coins-id-market-chart-range) documents price retrieval. [BigQuery public datasets](https://docs.cloud.google.com/bigquery/public-data) documents the cloud execution model; source-specific coverage still requires validation.
- [Evolving NEAR Tokenomics](https://www.near.org/blog/evolving-near-tokenomics) explicitly leaves deployment of economic tools to governance. It is not a commitment to future buybacks, burns, token price appreciation or holder entitlement.

## Required provider enablement record

For each enabled adapter store exact endpoint/method/schema hash, auth type and secret location, approved purpose, documented quota plus conservative local cap, oldest/newest dates verified, pagination proof, definition and time convention, expected lag, retry policy, licensing/redistribution evidence URL/date, provider lineage and a small sanitized probe artifact. Unknown limits disable scheduled collection by default. Archive receipts alone do not resolve rights for public raw-data downloads.

Verify a low-cost public finalized-header series first as the live candidate. Its operational probe is future NI-026 work; it was not performed in this documentation phase. Intents/revenue historical refresh remains blocked until actual access and attribution are verified.
