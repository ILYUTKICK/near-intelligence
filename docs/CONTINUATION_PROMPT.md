# Актуальное задание для продолжения

Указание владельца от 12 ноября 2026 заменяет прежний handoff, начинавшийся с NI-043:

**Сохранить почти готовый дизайн → реализовать все зарегистрированные P0/P1/P2 → проверить весь продукт локально с графиками → только затем размещать.**

Передай агенту [полный промпт завершения и приёмки](FINISH_BEFORE_DEPLOY_PROMPT.md), [PLAN.md](../PLAN.md) и актуальный checkout/архив проекта. Claims и статусы проверять в [TASKS.md](TASKS.md); закрыть NI-044/045/055/059/071/072, рабочие NI-060/065 и точечные NI-078 до NI-079, не пересоздавать уже выполненные задачи. Размещение NI-067 зависит от NI-079 DONE.

Предыдущие результаты и разрешения не удалены из карточек задач и PLAN. Активные claims, границы данных/расходов, merge только владельцем и исключение мобильного scope сохраняются. Этот файл — указатель на одно актуальное задание, не второй реестр статусов.
